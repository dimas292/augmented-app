# Augemented App

Unity AR project built with Vuforia Engine.

## Setup

The Vuforia Engine package is not stored in this repository because it is larger than GitHub's 100 MB file limit.

1. Download Vuforia Engine 11.4.4 for Unity (`com.ptc.vuforia.engine-11.4.4.tgz`) from https://developer.vuforia.com/downloads/sdk.
2. Place the file in the `Packages/` folder.
3. Open the project in Unity.
